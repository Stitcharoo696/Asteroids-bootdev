This was a project from a Python learning site Boot.dev
While the base function of the Asteroids game is from the learning path I have made my own modifications to it to make it more uniquely mine.
I did use Boot.dev's "code assist" AI for education on Python functionality with Boot.dev's teaching AI assistant.

The parts of the Asteroids code that are mine are:
-scoring system and score display
-different asteroids have different effects once they are broken down to their smallest compoents
if tiny asteroids:
-normally spawned white asteroids are worth the least points
-yellow are worth more than white
-red are worth the most and break into small rocks that endanger the player
-blue explode and increase the score based on how many things are caught in the blast radius
